BAIDJI MOHA PHOTO — النظام المتكامل المحلي

المكونات:
- index.html: بوابة العميل والطلبات والتتبع.
- admin.html: لوحة إدارة الطلبات والعملاء والألبومات والصور والرسائل.
- server.py: خادم Python محلي + SQLite.
- hero-bg.png: خلفية رقمية ليلية مستوحاة من الأرض والتصوير.
- start.bat: تشغيل الخادم على Windows.

التشغيل:
1) ثبّت Python 3.9+ على Windows.
2) شغّل start.bat.
3) افتح http://localhost:8000
4) لوحة الإدارة: http://localhost:8000/admin
